# AngularJS Practice Assignments

This repository contains three practical assignments developed using **AngularJS 1.x**.

## Assignment 1 – AngularJS Fundamentals

Demonstrates the basic concepts of AngularJS, including:
- AngularJS modules and controllers
- Two-way data binding using `ng-model`
- Directives such as `ng-repeat`, `ng-if`, and `ng-show`
- Adding subjects dynamically

## Assignment 2 – Farmer Registration Form

A farmer registration form with:
- Farmer name, mobile number, address, village, and crop fields
- Required-field validation
- Mobile number validation using `ng-pattern`
- Success message after valid submission

## Assignment 3 – REST API Integration

Demonstrates communication with a REST API using AngularJS:
- GET request to retrieve and display users
- POST request to submit new user details
- API response handling and error messages

**API Used:** [JSONPlaceholder](https://jsonplaceholder.typicode.com/)

*Note: JSONPlaceholder is a testing API. POST requests are simulated and do not permanently save new users.*

## Technologies Used

- HTML
- CSS
- JavaScript
- AngularJS 1.8.3
- REST API

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using the Live Server extension.
4. Navigate through the three assignments.
